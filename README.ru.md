# LumaTranslate Classic

**Бесплатный переводчик для Windows 10 и 11 (x64).**

[English](README.md) · [Скачать последнюю версию](https://github.com/PrimeLuxeS/LumaTranslate/releases/latest)

LumaTranslate — самостоятельное приложение для перевода текста в Windows. Поддерживает глобальные горячие клавиши, распознавание текста с экрана и установку через графический мастер.

## Возможности

- Перевод выделенного текста, буфера обмена и текста в окне программы.
- Редактируемые глобальные горячие клавиши и всплывающие окна перевода.
- Google, Bing, DeepL, Яндекс, PROMT и MyMemory (доступность сервисов может меняться).
- Распознавание текста: локальный Windows OCR либо дополнительный OCR.space.
- Темы оформления, настройки прокси, языки и история переводов.
- Проверка обновлений через GitHub Releases с проверкой SHA-256.

## Установка

1. Перейдите в [Releases](https://github.com/PrimeLuxeS/LumaTranslate/releases).
2. Скачайте **LumaTranslate-Setup.exe** из последней стабильной версии.
3. Запустите установщик. По желанию включите создание ярлыка на рабочем столе.

Стандартный путь установки — `C:\Program Files (x86)\LumaTranslate`. Windows запросит подтверждение администратора (UAC). Удалить приложение можно через **Параметры Windows → Установленные приложения**, **Панель управления → Программы и компоненты** или **Настройки → Обновление и удаление → Удалить приложение** в самой программе.

Установщик пока **не подписан цифровой подписью**. Windows SmartScreen может показать предупреждение. Скачивайте программу только из официальных Releases.

## Конфиденциальность

Настройки и история хранятся локально в `%LOCALAPPDATA%\LumaTranslate`. Windows OCR распознаёт текст на устройстве. При включении OCR.space изображение передаётся стороннему сервису. Онлайн-перевод отправляет текст выбранному провайдеру.

## Загрузка и исходный код

Этот публичный репозиторий предназначен для распространения приложения. В релизах публикуются **установщик Windows** и **контрольная сумма SHA-256**, а исходный код разработки хранится отдельно. Оригинальные бинарные файлы QTranslate здесь не распространяются.

LumaTranslate — независимое приложение, не связанное официально с QTranslate, Microsoft или сервисами перевода. Права на сторонние компоненты и названия принадлежат их владельцам.
