## Возможности

- **6 переводчиков:** Google, DeepL, Яндекс, Bing, PROMT и MyMemory. Переключение сервисов и резервный перевод при ошибке.
- **Перевод выделения:** всплывающее окно поверх других приложений, включая поддерживаемые поля Steam и браузеров.
- **Перевод с заменой:** переводи выделенный текст и вставляй результат на его место.
- **Исправление раскладки EN ↔ RU:** для слова или целого текста. Rekey дополнительно определяет ошибочную раскладку по словам.
- **Исправление русских опечаток** перед переводом, включая ошибки, требующие учёта контекста.
- **OCR:** распознавание текста с выбранной области экрана через Windows OCR или OCR.space.
- **Режим мыши:** перевод выделения, значок рядом с текстом и озвучивание.
- **Словарь, история, избранное, озвучка** и виртуальная клавиатура.
- **Настраиваемые горячие клавиши**, светлая и тёмная темы, оформление всплывающего окна, прокси и исключения для приложений.

## Горячие клавиши

| Действие | По умолчанию |
| --- | --- |
| Перевести выделение | `Ctrl+Q` |
| Перевести и заменить выделение | `Ctrl+S` |
| Исправить раскладку EN ↔ RU | `Ctrl+Alt+L` |
| Перевести буфер обмена | `Ctrl+Alt+T` |
| Распознать текст с экрана | `Ctrl+Shift+O` |
| Открыть словарь для выделения | `Ctrl+Shift+Q` |
| Озвучить выделение | `Ctrl+E` |

Все сочетания можно изменить или отключить в настройках. Доступен также перевод двойным нажатием `Ctrl`. Учитывай, что `Ctrl+S` в некоторых программах используется для сохранения.

## Установка

Скачай [**LumaTranslate-Setup.exe**](https://github.com/PrimeLuxeS/LumaTranslate/releases/latest), запусти установщик и при желании создай ярлык на рабочем столе. Удалить приложение можно через настройки Windows.

**Важно:** онлайн-перевод требует интернет, но не требует личных API-ключей переводчиков. Локальный Windows OCR работает без интернета; для OCR.space нужен отдельный ключ. Работа с выделением зависит от возможностей конкретного приложения.
