# LumaTranslate Classic

**Бесплатный переводчик для Windows: глобальные горячие клавиши, исправление текста и распознавание экрана.**

Windows 10/11 x64 · C# · WPF · .NET 10

[English](README.md) · [Скачать установщик](https://github.com/PrimeLuxeS/LumaTranslate/releases/latest)

</div>

## Что делает LumaTranslate

LumaTranslate переводит текст в собственном окне и в других приложениях Windows. Можно выделить фразу, вызвать перевод во всплывающем окне, заменить выделение переводом, перевести буфер обмена, озвучить текст, распознать область экрана, исправить неправильную раскладку EN ↔ RU или опечатки перед отправкой перевода.

**Перевод выполняется через интернет-сервисы.** Исправление раскладки, встроенные модели Rekey, правила подготовки русского текста и локальный Windows OCR не требуют ключа API переводчика. Облачный OCR.space — отдельный режим, которому нужен собственный API-ключ.

## Полный разбор возможностей

| Возможность | Как работает |
| --- | --- |
| **Перевод текста** | Поля ввода и результата, выбор языков, автоопределение исходного языка, смена сервиса, обратный перевод |
| **Перевод выделения** | Быстрый перевод выделенного текста в другой программе через всплывающее окно |
| **Замена выделения** | Получение текста из активного поля, перевод и вставка результата обратно |
| **Буфер обмена** | Перевод предварительно скопированного текста |
| **Исправление раскладки** | Прямое сопоставление клавиш EN ↔ RU и интеллектуальное исправление Rekey |
| **Исправление опечаток** | Русский словарь и осторожные контекстные правила перед переводом |
| **Режим мыши** | Значок рядом с выделением, автоматический перевод либо перевод с озвучкой |
| **OCR** | Распознавание выделенной области экрана через Windows OCR или OCR.space |
| **Озвучивание** | Голосовое чтение исходного текста и перевода голосами Windows |
| **Словарь** | Поиск по английскому и русскому Викисловарю |
| **История и избранное** | Сохранение переводов, возврат к результатам и избранные фразы |
| **Интерфейс** | Светлая и тёмная темы, настройка всплывающих окон, трей и ярлыки |

### Сервисы перевода

Поддерживаются **Google, Bing, DeepL, Яндекс, PROMT и MyMemory**. В разделе «Настройки → Сервисы» можно отключать отдельные движки, проверять их доступность и включать переход к другому сервису при ошибке выбранного.

Обычные сервисы перевода не требуют ввода личного API-ключа. Однако подключение к ним не гарантировано: провайдеры могут менять интерфейсы, ограничения, поддерживаемые языки и правила доступа. В текущей реализации MyMemory требует явно выбранного исходного языка вместо «Авто».

### Как исправляется текст

1. **Русские опечатки.** Перед переводом применяется проверка слов и осторожное уточнение по контексту. Например, ошибочное приветствие «привит май друк» может быть подготовлено как «привет мой друг».
2. **Rekey.** Локальный движок использует частотные модели английского и русского языков, чтобы определять текст, случайно набранный в чужой раскладке. Его можно включить перед переводом и отдельно — после пробела в поле LumaTranslate.
3. **Прямое исправление EN ↔ RU.** Отдельная горячая клавиша преобразует символы по их физическому положению на клавиатуре, в том числе для выделенных фраз и знаков препинания.

**Исправление раскладки — не перевод.** Rekey и словарные правила применяются по уверенности и не обязаны изменять каждое неоднозначное слово.

### Перевод в Steam, браузерах и других приложениях

Для глобальных сочетаний LumaTranslate использует механизмы Windows, читает выделение через UI Automation и при необходимости прибегает к копированию через буфер обмена. При замене программа пытается вернуть фокус исходному полю и восстановить буфер обмена.

Не все программы позволяют читать выделение или вставлять текст программно. Сочетания других приложений, права процессов, встроенные браузерные редакторы и ограничения Windows могут мешать работе. Для таких программ предусмотрены исключения.

### Распознавание текста с экрана

- **Windows OCR:** распознавание локально, без отправки изображения в интернет. Нужны соответствующие языковые пакеты Windows.
- **OCR.space API:** облачное распознавание, нужен API-ключ; доступны движки 2 и 3.
- **Авто:** сначала OCR.space, а при поддерживаемой ошибке — Windows OCR.

Выбирается прямоугольная область экрана. Распознанный текст попадает в переводчик; можно автоматически перевести его и показать всплывающее окно. В режиме OCR.space изображение выбранной области передаётся по HTTPS, действуют лимиты сервиса. API-ключ защищён Windows DPAPI для текущего пользователя.

### Словарь, история, избранное и голос

Есть отдельные окна словаря (английский и русский Викисловарь), истории переводов, виртуальной клавиатуры EN/RU и списка избранного. Из истории можно вернуть прошлый текст и результат. Озвучивание использует голоса, установленные в Windows; наличие нужного языка зависит от системы.

## Все горячие клавиши по умолчанию

Каждое сочетание можно изменить или отключить в **«Настройки → Горячие клавиши»**. Глобальные команды предназначены для работы вне окна переводчика; локальные — только для основного или всплывающего окна.

| Действие | Клавиши | Где работает |
| --- | --- | --- |
| Всплывающий перевод выделения | `Ctrl+Q` | Глобально |
| Словарь для выделенного текста | `Ctrl+Shift+Q` | Глобально |
| Озвучить выделение | `Ctrl+E` | Глобально |
| Перевести буфер обмена | `Ctrl+Alt+T` | Глобально |
| Исправить раскладку EN ↔ RU | `Ctrl+Alt+L` | Глобально |
| Перевести и заменить выделение | `Ctrl+S` | Глобально |
| OCR выделенной области экрана | `Ctrl+Shift+O` | Глобально |
| Перевести текст | `Ctrl+Enter` | Главное окно |
| Очистить текст | `Ctrl+N` | Главное окно |
| Поменять языки | `Ctrl+I` | Главное окно |
| Открыть словарь | `Ctrl+D` | Главное окно |
| Открыть историю | `Ctrl+H` | Главное окно |
| Виртуальная клавиатура | `Ctrl+K` | Главное окно |
| Открыть настройки | `Ctrl+Alt+S` | Главное окно |
| Озвучить оригинал | `Ctrl+Shift+E` | Главное окно |
| Озвучить перевод | `Ctrl+Alt+E` | Главное окно |
| Копировать перевод | `Ctrl+Shift+C` | Всплывающее окно |
| Озвучить перевод | `Ctrl+Shift+E` | Всплывающее окно |
| Закрыть перевод | `Escape` | Всплывающее окно |

Также можно включить **двойное нажатие Ctrl** для перевода выделения. Сочетания проверяются на конфликты. Например, `Ctrl+S` в других программах часто отвечает за сохранение документа; при конфликте измените горячую клавишу или настройте исключение.

## Все разделы настроек

| Раздел | Что настраивается |
| --- | --- |
| **Основные** | Автозапуск с Windows, шрифт, опечатки, Rekey, родной и второй языки, история |
| **Горячие клавиши** | Включение глобальных сочетаний, переназначение команд, двойной Ctrl, диагностика |
| **Интернет** | Тайм-аут, системный прокси, отсутствие прокси, ручной HTTP/HTTPS/SOCKS5 или автоопределение, авторизация |
| **Сервисы** | Включённые переводчики, проверка соединения, резервный сервис при ошибке |
| **Языки перевода** | Поиск языков и настройка списка доступных вариантов |
| **Вид** | Светлая/тёмная тема, стиль окна, размер и положение всплывающего окна, прозрачность, рамка, цвета, кнопки |
| **Исключения** | Список программ и классов окон, в которых глобальные действия запрещены |
| **Расширенные** | Режим мыши, действия трея, обработка текста, Windows OCR и OCR.space |
| **Обновление и удаление** | Проверка GitHub Releases, включение проверки обновлений при запуске, удаление программы |

Часть элементов расширенных настроек оставлена в интерфейсе без полноценного действия — например, флажок «Переводить элементы GUI». Наличие элемента не означает, что эта функция реализована.

## Установка

1. Откройте [последний релиз](https://github.com/PrimeLuxeS/LumaTranslate/releases/latest) и скачайте **LumaTranslate-Setup.exe**.
2. Запустите графический установщик NSIS и подтвердите запрос Windows UAC.
3. При необходимости отметьте создание ярлыка на рабочем столе. Путь по умолчанию: `C:\Program Files (x86)\LumaTranslate`.
4. Запустите переводчик из меню «Пуск» или по ярлыку. Пока программа работает, доступно меню значка в трее.

В установщик входят приложение Windows x64, нативная библиотека Rekey и её языковые модели; отдельно устанавливать .NET не нужно. Удаление доступно в «Установленных приложениях» Windows, «Программах и компонентах» либо в настройках LumaTranslate.

Для обновлений используется GitHub Releases: установочный файл проверяется по SHA-256, установка требует подтверждения. **Установщик пока не имеет цифровой подписи**, поэтому Windows SmartScreen может показать предупреждение.

## Данные, конфиденциальность и ограничения

- Настройки, история и избранное хранятся в `%LOCALAPPDATA%\LumaTranslate\classic-settings.json`. Сохранение введённого текста зависит от настроек пользователя.
- Ключ OCR.space шифруется средствами Windows DPAPI. Указанные вручную данные авторизации прокси сохраняются в локальном файле настроек — к нему нужно ограничить доступ.
- Текст онлайн-перевода передаётся выбранному стороннему сервису. При облачном OCR передаётся выбранный фрагмент экрана.
- Windows OCR, исправление раскладки и локальные модели работают на компьютере. Озвучка зависит от установленных голосов Windows.
- Для онлайн-перевода и Викисловаря нужен интернет; на отдельные возможности влияют доступность провайдеров, языковые пакеты, ограничения приложений и права Windows.

## Технологии и структура

| Компонент | Реализация |
| --- | --- |
| Интерфейс | C#, WPF, .NET 10 |
| Взаимодействие с Windows | Глобальные перехватчики, регистрация сочетаний, UI Automation, буфер обмена |
| Перевод | Онлайн-адаптеры Google, Bing, DeepL, Яндекс, PROMT, MyMemory с обработкой ошибок |
| Исправление текста | EN/RU-клавиатура, русская орфография и контекст, нативный Rekey на Rust |
| OCR | Windows.Media.Ocr и OCR.space |
| Установка | NSIS, приложение Windows x64, SHA-256 |

**Публичный репозиторий предназначен для распространения установщика и документации.** Исходники разработки хранятся отдельно; оригинальные файлы QTranslate не публикуются. LumaTranslate — независимое приложение и не связано официально с QTranslate или сервисами перевода. Уведомления об используемых сторонних компонентах поставляются вместе с установленным приложением.
