## Features

- **6 translation providers:** Google, DeepL, Yandex, Bing, PROMT, and MyMemory, with switching and fallback when a provider fails.
- **Selected-text translation:** popup translation in supported fields in apps including Steam and browsers.
- **Translate and replace:** insert a translated result in place of selected text.
- **EN ↔ RU keyboard-layout correction:** fix a word or longer text. Rekey can detect a mismatched layout by examining words.
- **Russian typo correction** before translation, including contextual corrections.
- **Screen OCR:** recognize text in a selected screen region with Windows OCR or OCR.space.
- **Mouse mode:** translate a selection, show a nearby icon, or speak the translation.
- **Dictionary, history, favorites, speech**, and an on-screen keyboard.
- **Customizable shortcuts**, light/dark themes, popup appearance, proxy settings, and per-app exclusions.

## Keyboard shortcuts (Windows)

| Action | Default |
| --- | --- |
| Translate selected text | `Ctrl+Q` |
| Translate and replace selection | `Ctrl+S` |
| Correct EN ↔ RU keyboard layout | `Ctrl+Alt+L` |
| Translate clipboard | `Ctrl+Alt+T` |
| Recognize screen text | `Ctrl+Shift+O` |
| Open dictionary for selection | `Ctrl+Shift+Q` |
| Speak selected text | `Ctrl+E` |

All shortcuts can be changed or disabled in Settings. Double-`Ctrl` translation is also available. Note that `Ctrl+S` is used for Save in many applications.

## Installation

Download [**LumaTranslate-Setup.exe**](https://github.com/PrimeLuxeS/LumaTranslate/releases/latest), run the installer, and optionally add a desktop shortcut. Uninstall through Windows Settings.

**Note:** Online translation requires internet access, but no personal translation-provider API keys. Built-in Windows OCR works offline; OCR.space requires its own key. Selected-text operations depend on the target application's support.
